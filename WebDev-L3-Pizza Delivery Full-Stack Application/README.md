# Pizza Delivery App 🍕

A full-stack pizza ordering and management system developed as part of the **OIBSIP (Oasis Infobyte Internship Program)**.

---

## 🚀 Features

- **User Authentication**: Secure user registration and login.
- **Interactive Menu & Ordering**: Browse pizzas, customize orders, and checkout.
- **Admin Dashboard**: Manage inventory, view placed orders, and update delivery statuses.
- **User Dashboard**: Track active orders and order history.
- **Payment & Notifications**: Integration ready for payment workflows and order alerts.

---

## 🛠️ Tech Stack

### Frontend
- **React.js** (Vite)
- **React Router DOM**
- **Axios**
- **Vanilla CSS**

### Backend
- **Node.js** & **Express.js**
- **MongoDB** & **Mongoose**
- **JWT (JSON Web Tokens)** & **Bcrypt.js**
- **Razorpay** & **Nodemailer**

---

## 💻 Getting Started

### 1. Backend Setup
```bash
cd pizza-app/backend
npm install
npm run dev # or npm start
```

### 2. Frontend Setup
```bash
cd pizza-app/frontend
npm install
npm run dev
```
